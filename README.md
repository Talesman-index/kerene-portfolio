# Portfolio Professionnel — Kérène OROU ZIME
### Beauté • Dermocosmétique • Nutrition • Conseil Client

Un portfolio interactif haut de gamme conçu selon l'esthétique scientifique et lumineuse de la marque **Lumiére**.

---

## ✨ Fonctionnalités Clés

- **Système Bi-Mode Intelligent** :
  - **Mode Défilement (Web Scroll)** : Lecture web fluide et continue, navigation sticky par ancres et menu tiroir mobile animé.
  - **Mode Présentation (Slide Deck)** : 10 diapositives plein écran (`Page 1 / 10`), transitions fluides, contrôles au clavier (`←` / `→` / `Espace`), swipe tactile et manette de navigation.
- **Exportation & Impression PDF A4 Haute Définition** :
  - Calibrage strict de chaque diapositive sur 1 page A4 standard (`297mm`).
  - Suppression automatique des en-têtes/pieds de page navigateurs (`file://`, date).
  - 10 pages nettes sans aucune coupure de carte.
- **Détourage & Effets Holographiques** :
  - Visage héro intégré sans fond avec maillage de scan et mapping facial optique.
  - Étiquettes d'analyse translucides en verre givré (`backdrop-filter`).
- **Composants Interactifs** :
  - Curseur comparateur avant/après pour illustrer l'évolution cutanée.
  - Tableau des actifs scientifiques dermocosmétiques (Niacinamide, Acide azélaïque, Vitamine C, etc.).
  - Modale interactive d'échange et formulaire de contact direct.
  - 100% icônes vectorielles SVG épurées (zéro emoji).

---

## 🛠️ Technologies Utilisées

- **HTML5 Sémantique**
- **CSS3 Avancé** (Variables CSS, Glassmorphism, CSS Grid, Transitions Cubic-Bezier, `@media print`)
- **JavaScript Vanilla** (State Machine, Navigation Synchrone, Keyboard & Touch Controllers)
- **Typographie** : Cormorant Garamond & Plus Jakarta Sans (Google Fonts)

## 🚀 Lancement en Local

Pour visualiser le portfolio en local :

```bash
# Avec Python
python3 -m http.server 8080

# Ou avec npx serve
npx serve .
```

Ouvrez ensuite votre navigateur sur `http://localhost:8080`.
